# Archisha Portfolio — Project Skill

## Purpose

This skill defines the design, content, implementation, and interaction rules for building Archisha Gupta's personal portfolio.

The portfolio is inspired by the visual language and interaction quality of the NIRMAAN 2026 website:

https://nirmaan-2026-tau.vercel.app/

The goal is NOT to clone NIRMAAN.

The goal is to create an original personal portfolio that uses the same broad visual grammar:

- editorial
- tactile
- colorful
- asymmetric
- playful
- technical
- information-rich
- experimental

The final website should feel like a designed digital artifact rather than a conventional resume website.

# 3. Design Personality

The portfolio should feel:

**EDITORIAL**
Like a sophisticated printed publication or poster.

**BRUTALIST**
Strong borders, bold type, direct visual hierarchy.

**PLAYFUL**
Unexpected objects, colors, interactions, and compositions.

**TECHNICAL**
Small labels, metadata, diagrams, coordinates, system-like elements.

**TACTILE**
Cards should feel physical through borders and offset shadows.

**COLORFUL**
Use accent colors strategically rather than creating a rainbow interface.

**EXPERIMENTAL**
The website should contain at least a few memorable interactive moments.

Avoid making the website feel like a standard portfolio template.

# 5. Typography

Typography is a major part of the design.

## Display typography

Use a bold contemporary sans-serif / grotesk.

Characteristics:

- heavy weight
- large scale
- tight line height
- slightly negative tracking
- strong visual presence

## Technical typography

Use a monospace or compact technical font for:

- section numbers
- metadata
- coordinates
- dates
- small labels
- status indicators
- technical annotations

## Hierarchy

Maintain strong contrast between:

- huge display text
- medium headings
- readable body text
- tiny technical labels

Never make every element large.

---

# 6. Layout System

Use an editorial asymmetric grid.

## Desktop

12-column grid.

Allow:

- uneven column spans
- offset cards
- overlaps
- large/small elements
- intentional empty areas
- dense information clusters

Do not center everything.

## Tablet

8-column grid.

Preserve the editorial hierarchy.

## Mobile

4-column conceptual grid.

Recompose layouts rather than merely scaling desktop.

Mobile should feel like a deliberately designed vertical poster.

# 7. Cards

Cards should feel tactile.

Use:

- cream/light surface
- black border

- subtle offset black shadow

Avoid:

- glassmorphism
- soft floating cards

Keep rotations subtle.

# 8. Borders and Shadows

# 30. Animation Rules

Use Framer Motion.

Preferred animations:

- staged reveals
- fade-up
- clip reveals
- stagger
- subtle slide
- subtle scale
- hover movement
- card elevation
- image reveal
- marquee
- gentle parallax

Do NOT over-animate.

Avoid:

- excessive glitch
- aggressive distortion
- constant floating
- huge cursor effects
- excessive blur
- long transitions

Animation should support the design.

# 39. Design Review Checklist

Before considering a section complete, ask:

### Composition

- Does it feel editorial?
- Is the layout asymmetric where appropriate?
- Is there a good balance between density and whitespace?

### Typography

- Is the hierarchy obvious?
- Are large and small type sizes contrasting enough?
- Are technical labels appropriately small?

### Color

- Is cream the dominant canvas?
- Are accent colors intentional?
- Is the page avoiding rainbow overload?

### Cards

- Are borders visible?
- Are shadows tactile?
- Do cards feel physical?

### Interaction

- Does hover feel intentional?
- Are animations subtle?
- Does interaction add meaning?

### Originality

- Does it feel like Archisha's portfolio?
- Is it inspired by NIRMAAN without becoming a clone?
